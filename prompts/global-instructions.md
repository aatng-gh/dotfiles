# Writing rules (ASD-STE100)
These rules apply to chat responses, code comments, docs, commit messages, and PR descriptions.
- Write deductively: state the conclusion before the support.
- Use one term for each concept. Do not use synonyms for the same concept.
- Use the active voice. Name the actor.
- Keep sentences to 20 words or fewer (25 in descriptive text).
- Write one instruction per sentence. Write one topic per paragraph.
- Prefer simple tenses. Use other verb forms when the meaning needs them.
- Do not write noun stacks of more than three words.
- Use a vertical list for three or more parallel items.
- Keep articles and verbs. Do not compress sentences into fragments.
- Start each warning with the condition or the command.

# Accuracy rules
- State only facts from the source. If you must assume, mark the assumption in place.
